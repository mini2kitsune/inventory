# 在庫管理アプリ — 使い方ガイド

## 新しいスマホへの移行手順

### ① 旧スマホでの操作（旧端末にデータがある場合）

1. ブラウザで `inventory.html` を開く
2. メールアドレス・パスワードでログイン
3. 右上の歯車アイコン → 設定 を開く
4. **「📤 Supabaseへ移行（旧端末データ復元）」** をタップ
5. 確認ダイアログで「OK」
6. 「移行完了！」と表示されたら完了

### ② 新しいスマホでの操作

1. ブラウザで `inventory.html` を開く
2. メールアドレス・パスワードでログイン
3. **自動的にSupabaseからデータが読み込まれます**（操作不要）

---

## 通常の使い方

### ログイン

- アプリを開くとログイン画面が表示されます
- 登録済みのメールアドレスとパスワードを入力して「ログイン」
- ログイン状態はブラウザに保存されます（次回は自動ログイン）

### 新規アカウント登録

- ログイン画面の「新規登録」タブをタップ
- メールアドレスとパスワード（6文字以上）を入力
- 登録確認メールが届いたらリンクをクリック
- その後ログインしてください

### 在庫管理

| 操作 | 方法 |
|------|------|
| 在庫を増やす | 商品の「+」ボタン |
| 在庫を減らす | 商品の「−」ボタン |
| 変更を保存 | 下部バーの「保存する」ボタン |
| 商品の詳細編集 | 商品名をタップ |

### 発注

1. 「発注カゴ」タブを開く
2. 商品の「カゴ」ボタンで追加
3. 数量を調整
4. 「発注を確定する」ボタンをタップ
5. 発注チェックリストを確認・共有

### 端末間リアルタイム同期

- 複数の端末でログインすると、片方の変更がもう片方に即座に反映されます
- オフライン時はキャッシュから表示（復帰後に自動同期）

## よくある質問

**Q: 新しいスマホでデータが表示されない**  
A: ログインするだけでSupabaseからデータが自動読み込みされます。ログイン後もデータが空の場合は、旧端末で移行操作が完了しているか確認してください。

**Q: ログアウトしたい**  
A: 設定（歯車）→「ログアウト」

**Q: オフラインでも使える？**  
A: 最後にロードしたデータはキャッシュされています。ただし変更の保存はオンライン時のみ有効です。
